## 🔐 Algorithm Used

### Caesar Cipher

The Caesar Cipher is a substitution cipher where each letter in the message is shifted by a fixed number of positions in the alphabet.

### Encryption Formula

```text
E(x) = (x + n) mod 26
```

### Decryption Formula

```text
D(x) = (x + 26 - n) mod 26
```

Where:

* `x` = position of the letter (A = 0, B = 1, ..., Z = 25)
* `n` = shift value
